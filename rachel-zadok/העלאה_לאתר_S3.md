# העלאת התיק כאתר סטטי (S3 או כל אחסון סטטי)

התיקייה ערוכה כאתר סטטי מוכן: **רחל_צדוק_המחקר_המלא.html** הוא המסמך המאוחד, ו-**index.html** הוא שלד הפניה (redirect) שמפנה אליו אוטומטית — כך שכניסה לכתובת האתר פותחת ישר את המחקר. כל הקישורים יחסיים — למסמכי docs/‏, לתמליל, לניתוח העדות ולעץ המשפחה. אין צורך בשום שינוי.

## מה להעלות
את הקבצים האלה בלבד (כל השאר — קובצי עבודה):

- `index.html` + `רחל_צדוק_המחקר_המלא.html`
- `docs/` (כל התיקייה, כולל docs/thumbs/)
- `תמליל_העדות_המלא.txt`, `ניתוח_העדות.md`, `עץ_משפחה_גרפי.html`

## פקודה לדוגמה (AWS CLI)

```
aws s3 sync "רחל צדוק" s3://<שם-הדלי>/rachel/ \
  --exclude "*" \
  --include "index.html" --include "רחל_צדוק_המחקר_המלא.html" \
  --include "docs/*" \
  --include "תמליל_העדות_המלא.txt" --include "ניתוח_העדות.md" --include "עץ_משפחה_גרפי.html"
```

(גישת "הכללה בלבד" מבטיחה שקובצי העבודה — הקלטת העדות, דוחות הביקורת, קובצי ה-md של המקור, ארכיון_עבודה/ — לא יעלו בטעות.)

לאחר ההעלאה: להפעיל Static website hosting על הדלי (או להגיש דרך CloudFront), עם `index.html` כ-Index document. שמות קבצים בעברית נתמכים — S3 והדפדפנים מטפלים בקידוד אוטומטית.

*הערה: בסביבת העבודה נבנית גם תיקיית `site/` — עותק נקי ומאומת של בדיוק הקבצים האלה; אם היא זמינה, אפשר פשוט להעלות את תוכנה כמות שהוא.*
