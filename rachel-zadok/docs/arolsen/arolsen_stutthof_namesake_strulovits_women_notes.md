# Arolsen — two Strulovits-namesake women in the same Stutthof transport block as Rachel/Sima (29.6.1944 from Auschwitz) — NOT relatives

Source: Arolsen Archives online collections, 1.1.41.2 "Files with names from STRAUS" (same box as Rachel's 4653467 and Sima's 4653464; Archiv-Signatur 01014102 129.17x). Retrieved 2026-10-27.

1. STRULOVICS, DORA — doc 4653460, https://collections.arolsen-archives.org/en/document/4653460 — ref 01014102 129.170, 3 docs, prisoner 39295. Häftlings-Personal-Karte (scan 4653462): "Fam.-Name: Strulovics / Vorname: Dora / Geb. am 25.9.28 in Zadnia / Stand: led. / Religion: mos. Staatsang.: Ungarn / Wohnort d. Angehörigen: Vater: David St. - Adr. w.o. / Eingewiesen am 29.6.44 durch KL. Auschwitz in KL. Stutthof / erlernter Beruf: Landarbeiterin / Sprache: slow., deutsch". Files: stutthof_dora_strulovics_4653460/ (6 scans + citation json). Birthplace "Zadnia" = Zárnya (Carpathian Ruthenia). Father David, not Lajos/Leib -> **נשלל** as sister/relative (different father's name; different village). Note: DEGOB protocols 2704 and 3355 describe Zárnya.
2. STRULOWITZ, HELENE — doc 4653473, https://collections.arolsen-archives.org/en/document/4653473 — ref 01014102 129.174, 3 docs, prisoner 38830. Karte (scan 4653475): "Strulowitz / Helene / Geb. am 10.6.24 in Olszokoloczo / led. / mos. Ungarn / Wohnort d. Angehörigen: Vater: Samuel S. z.Z. KL Auschwitz / Eingewiesen am 29.6.44 durch KL Auschwitz in KL Stutthof / erlernter Beruf: Haushalt / Sprache: ungarisch-russisch". Files: stutthof_helene_strulowitz_4653473/. Father Samuel -> **נשלל** as sibling (father's name differs); "Olszokoloczo" (~Olaszkaloucz / Alsókalocsa?) not identified.
Value: shows the 29.6.1944 Auschwitz->Stutthof women's transport (block 37642-40143) carried at least four Strulovits-named girls (38443 Sary, 38444 Ruci, 38830 Helene, 39295 Dora) from different families; do not conflate. Grade: נשלל (as family), ככל הנראה (as transport context).
