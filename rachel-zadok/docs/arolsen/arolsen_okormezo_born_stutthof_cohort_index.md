Why it matters for Rachel Zadok (Strulowits Ruci #38444, sister Sary #38443; arrived Stutthof 29.6.1944 from Auschwitz in the 2,502-woman transport): these are women of the same hometown registered in the same number block (37875-39295), i.e. the companions of the sisters on the 17.5.1944 Ökörmező train / 19.5.1944 Birkenau selection / 29.6.1944 transfer. The report does not name any of them (checked: none of these surnames appears in רחל_צדוק_מחקר_מקיף.md except as bare surnames: Landau (Joel Landau, DEGOB 73), Schneider (Rita Schneider-Pollak) and Hoffmann (unrelated context)). Page 13 of the Stutthof museum's original transport list (docs/stutthof_museum_2026/POL-AMS-I-IIb-10-099.jpg, rows 771-835 = numbers 38412-38476) shows the same names in the same order, e.g. row 788 Weiser Fanny 38429, row 790 Weiss Sabina 38431, row 793 Zisowicz Etel 38434, row 801 'Zoldan/Soldan Roza 6.3.27' 38442 immediately before the sisters (802-803).
