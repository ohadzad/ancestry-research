# DEGOB protocol 1650 — two Ökörmező women: Auschwitz → Stutthof → Baumgart → Lubicz → Strasburg → Praust (liberated 23.3.1945)

- Source: DEGOB (National Committee for Attending Deportees), Hungarian original, degob.hu — https://degob.hu/index.php?showjk=1650 (scan: https://degob.hu/index.php?showjk_img=1650)
- Retrieved: 2026-10-27 via degob_get_protocol(1650). No English translation on degob.org.
- Survivors (verbatim metadata, names anonymised on the site):
  - D. S. — nő, Születési idő 1930, Foglalkozás: diák, Utolsó lakóhely: Ökörmezõ, Táborok: Auschwitz, Stutthof, Baumgart, Lubics, Strassburg, Praust
  - D. F. — nő, Születési idő 1921, Foglalkozás: varrónõ, Utolsó lakóhely: Ökörmezõ, Táborok: same
- Key verbatim passages (Hungarian):
  - "Mi aztán transzportba kerültünk egy választás alkalmával, és elvittek bennünket Stutthofba."
  - "Innen elkerültünk Baumgartba egy Arbeitslagerba ... futóárkokat csináltunk. Napi 11 órát dolgoztunk"
  - "elvittek bennünket Lubicsba. Itt Zeltben laktunk" ... "10 hét után megint továbbvittek, és így kerültünk Strassburgba" ... "Kétheti gyaloglás után érkeztünk meg Praustba."
  - "Így voltunk itt március 23.-ig, amikor bejöttek az oroszok és azok felszabadítottak bennünket."
- Relevance to Rachel Zadok (née Strulovits/Farkas, b. 16.4.1929 Volove/Ökörmező; Stutthof 38444; Thorn; death march; liberation): NOT Rachel (D.S. b. 1930, D.F. b. 1921). It is an independent 1945-46 witness from Ökörmező for the same chain Stutthof -> OT Thorn-area sub-camps (Baumgart, Lubicz near Thorn, Strasburg/Brodnica) -> death march -> Praust, liberation 23.3.1945. It matches the report's "external date" for Praust liberation (23.03.1945) against Rachel's "early February" and fills in sub-camp names (Baumgart, Lubicz, Strasburg) that the Stutthof museum could not assign to Rachel.
- Grade: ככל הנראה — contextual parallel only; does not mention Rachel, Sima or the Strulovits family. Sub-camp identifications (Lubics = Lubicz, Strassburg = Brodnica/Strasburg i. Westpr.) are my reading of the spelling, טעון אימות.
