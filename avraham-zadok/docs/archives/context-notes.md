# הערות הקשר היסטורי (מקורות משניים לרקע)

## חטיבת קרייתי (חטיבה 4)
מקור: המכלול, "חטיבת קרייתי" — https://www.hamichlol.org.il/חטיבת_קרייתי
- הוקמה בתל אביב בפברואר 1948 על בסיס פלוגות חי"ש, אחרי שחטיבת גבעתי הוצאה מהעיר לדרום.
- גבול החטיבה: המרחב העירוני של תל אביב, מנחל הירקון בצפון ועד בת ים בדרום ועד יאזור (אזור) במזרח.
- "החטיבה אבטחה את הדרכים מחולון וממקוה ישראל אל העיר" — קשר ישיר לאזור מגורי המשפחה.
- השתתפה במבצע חמץ (כיבוש יפו, מאי 1948) ובמבצע דני (לוד ורמלה, יולי 1948) — תואם "שירות במרחבי לוד ורמלה" שבתולדות אברהם.
- עם הקמת צה"ל הפכה לחטיבה 4.

## תעשיית כפתורי הצדף / קואופרטיב "דר"
מקור: עונ"ש (עונג שבת), "דַּר וְסֹחָרֶת: תעשיית כפתורי הצדף בארץ" — https://onegshabbat.blogspot.com/2025/06/blog-post_24.html
- תעשיית כפתורי צדף (אם-הפנינה) בארץ; ייצור כפתורים מקונכיות. הקואופרטיב/מפעל "דר" פעל משנות ה-50; בשנות ה-60 עבר בהדרגה לכפתורי פלסטיק.
- הערה: המקור מזכיר מפעל בבני ברק; עמוד הפלמ"ח מציין ש"דר" נמכר ב-1981. להציג את ההקשר כרקע ענפי, בלי לקבוע פרטי מיקום סותרים.

## מקווה ישראל
- בית הספר החקלאי הראשון בארץ, נוסד ב-1870 (חברת כל ישראל חברים / אליאנס). ליד חולון.
- אתר מורשת לאומי; משפחות עובדים ובעלי-מלאכה (אופה, נוטרים, מורים) התגוררו בשטח.
- ספר משפחת פריינטה (הספרייה הלאומית) מאשש שמשפחת פריינטה היא ממשפחות מקווה ישראל הוותיקות.
