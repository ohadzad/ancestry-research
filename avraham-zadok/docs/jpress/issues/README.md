# גיליונות JPress מלאים — עותקים מקומיים

התיקייה הזאת נועדה להחזיק את **קובצי ה-PDF של הגיליונות השלמים** שמהם נלקחו הידיעות
בקורפוס, כדי שאפשר יהיה לעיין במסמך המקורי בלי תלות באתר חיצוני — ולא רק בחיתוכי התצלום
ששמורים ב-`docs/evidence/`.

## למה ההורדה אינה אוטומטית

הורדת גיליון מלא מ-JPress עוברת דרך **reCAPTCHA** של הספרייה הלאומית (הכתובת המתקבלת
נושאת `pdfaccesscode` ו-`g-recaptcha-response`). מנגנון כזה קיים בדיוק כדי למנוע הורדה
אוטומטית בכמות, ולכן השלב הזה נעשה **ידנית** ואינו מתבצע בסקריפט. הצפייה בגיליון בדפדפן
עובדת כרגיל; רק ההורדה חסומה לאוטומציה. (מן הענן האתר חסום ממילא ב-Cloudflare, 403.)

## מה להוריד

לכל שורה: פתחו את הקישור, ובצפיין ה-PDF של כרום לחצו על סמל ההורדה (⤓) בפינה.
הקובץ יישמר בתיקיית ההורדות, ומשם ייקלט לכאן בשמו הקנוני.
