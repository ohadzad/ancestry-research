# מחקר שורשי המשפחה — ארכיון

צדוק · פריינטה · ארואס · סטרולוביץ · רפפורט · פרקש · שטיינר · דהן · בן הרוש

ארכיון מחקר גנאלוגי מתועד־מקורות. האתר החי:
**https://ohadzad.github.io/ancestry-research/**

## מבנה

```
index.html               ← עמוד השער (נבנה מ-research_registry.json)
research_registry.json   ← רשימת המחקרים והאנשים שבהם
build_portal.py          ← בונה את index.html ובודק שכל הקישורים היחסיים קיימים
.nojekyll                ← מונע מ-GitHub Pages לסנן קבצים בשמות עבריים
rachel-zadok/            ← מחקר: רחל צדוק לבית סטרולוביץ־רפפורט (1929–2021)
avraham-zadok/           ← מחקר: אברהם צדוק (1925–2017)
miriam-benharoush/       ← מחקר: מרים בן הרוש לבית דהן (מכנאס, נ׳ 1939) — בתהליך
mordechai-benharoush/    ← דף נלווה: מרדכי בן הרוש (1931–2010) — בתהליך
```

כל תיקיית מחקר עצמאית לחלוטין — הדוח, עצי המשפחה, אינדקס המקורות, סקריפטי הבנייה
וכל מסמכי המקור שלה יושבים בתוכה, וכל הקישורים בתוכה יחסיים. אפשר להעביר תיקיית מחקר
למקום אחר בלי לשבור דבר.

## הוספת מחקר חדש

1. צרו תיקייה `<slug>/` ובה `index.html` (או דוח בשם כלשהו + stub הפניה).
2. הוסיפו רשומה למערך `researches` שב-`research_registry.json`.
3. הריצו `$PY build_portal.py` מתיקיית השורש. הבנייה נכשלת אם קישור יחסי כלשהו שבור.

## סביבת פייתון

הבנייה דורשת `markdown` ו-`pillow`, ורצה מתוך סביבה וירטואלית שיושבת **מחוץ**
לתיקייה (כדי שדרופבוקס לא יסנכרן אותה):

```bash
PY=~/.venvs/ancestry-research/bin/python
# פעם אחת:
python3 -m venv ~/.venvs/ancestry-research && $PY -m pip install markdown pillow
```

## בנייה מחדש

```bash
$PY build_portal.py                # עמוד השער + אינדקס האנשים (people.html)
$PY rachel-zadok/build.py          # כל מחקר — הסיפור, הדוח המלא ועותק site/
$PY avraham-zadok/build.py
$PY miriam-benharoush/build.py
$PY mordechai-benharoush/build.py
```

ארבעת הדוחות נבנים מאותו מנוע, `common/genealogy_site/`, ולפי אותו שלד; ה-`build.py`
שבתיקיית הפרויקט אינו אלא ההצהרה של אותו פרויקט — הגוון, קובצי המקור, האנשים
והתצלומים. המפרט המלא, ובכללו מתכון בן שמונה שלבים להסבת דוח קיים, נמצא
ב-[`common/TEMPLATE.md`](common/TEMPLATE.md).

כל מחקר מוגש ב**שני עמודים**: *הסיפור* — החיים לפי סדר הזמן, עם ציר זמן, שלוש עמודות
ודאות וכרטיסי מסמך, לקורא שנחת בלי הקשר; ו*הדוח המלא* — כל הראיות, המועמדים שנשללו,
אינדקס המקורות והשיטה. `index.html` של כל תיקייה נפתח בסיפור; שם הקובץ של הדוח אינו
משתנה לעולם, כדי שכל עוגן שנשלח או צוטט ימשיך לעבוד.

הבנייה עוברת בכל פעם דרך שערי בקרה — קישורים, עוגנים, מבנה תגיות, הגנת כיווניות,
טקסט חלופי לתמונות, פרטיות, אורך הלִיד, מספר הקישורים בניווט, והעוגנים שהסיפור
מקשר אליהם בדוח — ונעצרת ברעש אם משהו נכשל.

## שיטה

כל קביעה נשענת על מקור כפול — קישור אל הרשומה בארכיון המקורי וקישור אל עותק שמור
בתוך תיקיית המחקר. הראיות בגלריה הן חיתוכים מן העמוד המקורי, ולחיצה עליהן פותחת את
הקובץ המלא. סולם הוודאות אחיד: מאומת · כמעט ודאי · ככל הנראה · טעון אימות · נשלל (ובמעקב — בוטל); מסמך מדורג בנפרד מן הזיהוי שנשען עליו.
ציטוט בשפה זרה מלווה תמיד בתרגום. גם ממצא שלילי נרשם.
