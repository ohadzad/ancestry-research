# מחקר גנאלוגי — רחל צדוק (לבית סטרולוביץ-רפפורט)

מחקר תיעודי על **רחל ("רוצי") צדוק**, לבית סטרולוביץ-רפפורט (ברישום האזרחי: פרקש) — ילידת **16.04.1929** בוולובה / Ökörmező / מיז'יריה (זקרפטיה, אוקראינה של היום), ניצולת אושוויץ, שטוטהוף וטורן, שנפטרה בחולון בינואר 2021. המחקר משחזר את שבע הדורות של המשפחה, את מסלול הרדיפה בשואה, ואת גורל בני המשפחה — הכול מבוסס על מסמכים ומקורות ראשוניים, עם קישור כפול (מקור חיצוני מדויק + עותק פנימי) לכל קביעה.

## האתר החי

📖 **[רחל_צדוק_המחקר_המלא.html](רחל_צדוק_המחקר_המלא.html)** — המסמך המאוחד: הדוח המלא, תצלומי הראיות, עץ המשפחה והאינדקס, בקובץ HTML אחד.

## מקורות עיקריים

עדות הווידאו של רחל (יד ושם, 2009); רשומות יד ושם (מאגר השמות ודפי עד); ארכיון ארולסן ומוזיאון שטוטהוף; מאגר מוזיאון אושוויץ; הרשומות האזרחיות של תת-הקרפטים (JewishGen, פונד 1606 בארכיון DAZO); מפקד קרפטליה 1921 (Hungaricana); ארכיון העיתונות ההונגרי (Arcanum/ADT); אתר קהילת מיז'יריה (KehilaLinks). הפירוט המלא — ב[אינדקס המקורות](אינדקס_מקורות.md) ובפרק המקורות של הדוח.
